# 穩出貨

靈芝蟲草出貨流程的三個小工具，做成靜態網頁放在 GitHub Pages。

| 檔案 | 做什麼 |
|---|---|
| `index.html` | 入口：四張卡片＋換名單（貼試算表網址） |
| `sticker.html` | 姓名貼紙產生器（A4 3欄×8列，Code 128 條碼，附裁切線） |
| `check.html` | 掃條碼核對（掃描槍讀 `event.code`，繞過中文輸入法） |

名單不寫在這裡，是開頁時去 Google 試算表撈的。
後台是一支 Apps Script Web App，要通行碼才回資料；通行碼**不在原始碼裡**，
第一次打開網頁會問，之後存在該台電腦的瀏覽器。

列印：A4／縮放 100%／邊界「無」／關頁首頁尾／**不要勾無邊界列印**。
