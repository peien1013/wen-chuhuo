🔫 出貨核對 — 掃條碼點名

每包貼好姓名貼紙後，一個一個掃過去。少誰、重複掃，畫面立刻告訴你。

按「▶ 開始掃描」後，拿掃描槍掃商品上的條碼
看：
已掃 0 / 0 還差 0 個
未啟用 未連線
⚙ 名單與編號設定（換一批人時才要動）

規則跟「姓名貼紙產生器」一模一樣，所以編號一定對得起來。 一行一人；第二欄可填自訂編號（逗號或 Tab 分隔）。
換名單會清掉目前的掃描紀錄。

掃不動的話：先用記事本測，記事本也亂碼＝輸入法問題（這頁已經用實體鍵位繞過，正常不會發生）； 記事本正常但這頁沒反應＝忘了按「▶ 開始掃描」，或焦點跑到輸入框裡了（點一下空白處再掃）。
掃描槍要設成掃完自動送出 Enter，否則不會觸發。
每掃一筆會即時寫進試算表的「掃描紀錄」分頁，換一台電腦打開也會自動載入已掃的，不怕關頁面。萬一連不上網，仍然可以照掃（存在本機），只是不會同步。
